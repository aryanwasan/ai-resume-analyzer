# AI Resume Analyzer

## What it does

Compares a resume against a job description using a custom keyword list
and returns a match percentage, showing which skills are matched and which are missing.

## How to run

Run the program and provide 3 file paths when prompted:

1. Resume file path
2. Job description file path
3. Keywords file path

## Example output

Enter resume file path: test.txt
Enter job file path: job.txt
Enter keyword file path: keywords.txt
Matched: {'analysis', 'python', 'data'}
Missing: {'deep', 'machine', 'learning'}
Score 42.86 %
